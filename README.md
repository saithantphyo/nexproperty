# NEXPROPERTY

NEXPROPERTY real-estate website with public listings and an admin panel.

## Features
- Add, edit, and delete properties
- Upload property images or use image URLs
- Search/filter properties
- Admin-editable website name, logo, hero text, phone, address, and theme color
- SQLite database

## Run
1. Install Node.js LTS.
2. Open Terminal/PowerShell in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

Admin: `admin` / `admin123` (change these credentials in server.js before production).

Note: Netlify Drop can host the public static files, but this full Admin + SQLite version needs a Node.js-capable server.
